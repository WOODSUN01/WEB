# 向容大師紫微能量好運學院

「向容大師紫微能量好運學院」繁體中文、Mobile-first 的品牌網站。

## 線上網站

<https://woodsun01.github.io/WEB/>

## 部署方式

此專案為純靜態網站，GitHub Pages 直接從 `main` 分支的根目錄提供 `index.html`。
不包含付款、預約、會員或其他伺服器端功能；這類功能啟用時應改由具備後端與安全設定的服務處理。

## 本機預覽

直接以瀏覽器開啟 `index.html` 即可預覽。網站使用外部字型與 Tailwind Browser CDN，完整呈現需要網路連線。

## 內容與安全

- 不要將 `.env`、憑證、私鑰、存取權杖或客戶資料加入版本控制。
- 社群分享封面位於 `images/og-cover.png`。
